# 第 1 课：让电脑打字给你看 —— 程序是什么，怎么让它跑起来

> 这门课假设你**从来没写过代码**。不需要数学好，不需要懂电脑原理，只要你会复制粘贴、
> 会在终端里敲字。每一课只教你**两个新词**，其余全用大白话。
>
> 这一课的新词只有两个：**程序**、**编译**（见第 5 节）。
> 本课所有代码都在自己电脑上跑过，屏幕上的输出我原样抄在下面，没有编造。

---

## 1. 今天只弄懂一件事

电脑平时什么也不做。你给它写一小段话，它就会照着做，并把结果打在屏幕上。

这段"写给它的话"，就叫**程序**。今天你要写出人生第一个程序，让它做三件事：

1. 打出一句中文；
2. 算一道乘法并把答案打出来；
3. 打很多行。

就这些。不讲原理，不背定义——先让它跑起来。

## 2. 先跑起来看（请逐字照做）

打开终端（Mac 上叫 Terminal），一行一行敲下面的命令。`$` 是终端的提示符，**不要敲它**：

```bash
cargo new --bin hello        # 建一个空项目，名字随便取
cd hello                     # 走进这个项目的文件夹
cat src/main.rs              # 看看里面现在有什么
```

第三条命令会打出这个（这是 `cargo` 自动帮你生成的起点）：

```rust
fn main() {
    println!("Hello, world!");
}
```

用编辑器的"全部替换"，把它换成今天的内容：

```rust
fn main() {
    println!("你好，电脑");
    println!("我会算数：6 乘 7 等于 {}", 6 * 7);
    println!("我可以写很多行：第一行、第二行、第三行");
}
```

存盘，然后在终端里敲：

```bash
cargo run
```

你会在屏幕上看到（这就是我电脑上的真实输出）：

```
你好，电脑
我会算数：6 乘 7 等于 42
我可以写很多行：第一行、第二行、第三行
```

**恭喜，你已经写完并运行了一个程序。** 上面那一行 `cargo run` 里藏着一个动作，第 5 节讲它。

如果没看到这三行，先别往下读——回头检查：字有没有敲错？存盘了没？（新手 90% 的时间卡在这两件小事上，这很正常。）

## 3. 你猜会发生什么（先猜，再改，再跑）

把文件改成下面三行，每改一次就跑一次 `cargo run`，看看和你猜的是不是一样：

| 你改成 | 你猜屏幕会出现什么 |
|---|---|
| `println!("你好，电脑");` 删掉这一整行 | 少一行？还是报错？ |
| `6 * 7` 换成 `6 * 7 + 1` | 42？还是 43？ |
| 第三行的 `println!` 后面内容清空：`println!("");` | 报错？还是打一个空行？ |

第三条的答案可能和你猜的不一样：**它会打出一个空行，不报错**。电脑很笨，也很老实——
你让它打空的东西，它就打空的东西，它不会替你觉得"这大概是写错了"。

记住这个感觉：**电脑不会猜你的心意，你写什么它做什么。** 后面所有报错，都是这个原因。

## 4. 一行一行看（每一行都不放过）

```rust
fn main() {
```

- `fn` 是"我要开始描述一件事了"的记号（它是英文 function 的缩写，但你现在不需要管英文，
  只需要知道：**看到 `fn`，就知道后面给它起的名字代表一件事**）。
- `main` 是这件事的名字。**这个名字必须是 `main`**，不能改成别的——因为电脑运行一个程序时，
  固定要去找名叫 `main` 的这件事，找不到就罢工（第 6 节第一条报错就是它）。
- 结尾的 `{` 意思是"这件事的具体内容从这儿开始"。内容写完要用 `}` 收尾（看最后一行）。

```rust
    println!("你好，电脑");
```

- `println!` 是"往屏幕上打一行字，然后在末尾自动换行"的意思。
  后面那个 `!` 是它长得和别的不一样的地方，你现在只要记住"**有它**"。
- 括号里两个引号中间的部分 `你好，电脑`，就是要打出来的内容，原样照打。
- 结尾的 `;`（分号）表示"这一句说完了"。像中文里的句号。少了它，电脑会以为你话没说完
  （第 6 节第二条报错就是它）。

```rust
    println!("我会算数：6 乘 7 等于 {}", 6 * 7);
```

- 这一句里有两样东西，用逗号隔开：
  - 第一个：带引号的那句话，里面有一个 `{}`——它是**一个空位**，意思是"待会儿有东西填进来"；
  - 第二个：`6 * 7`，是要填进空位的东西。`*` 是乘号。
- 电脑先把 `6 * 7` 算出 42，再把 42 放进那个空位，所以屏幕上出现"6 乘 7 等于 42"。
- 空位可以有好几个，按顺序填：
  `println!("{} 加 {} 等于 {}", 1, 2, 1 + 2);` → 屏幕上是 `1 加 2 等于 3`。

```rust
    println!("我可以写很多行：第一行、第二行、第三行");
```

- 又是一句。它和上面两句的关系是：**从上到下，一句一句做**。谁写在前面谁先做。

```rust
}
```

- 收尾的 `}`：告诉电脑"`main` 这件事的内容到此为止"。
  它必须和第 1 行的 `{` 成对出现，**多一个少一个都不行**。

## 5. 现在给两件事起名字（本课仅有的两个新词）

**程序**：你写给电脑的一串指令，存在一个文件里。它本身不会自己动起来——刚才那段文字放在
`src/main.rs` 里时，屏幕上什么都没有；你敲下一条命令让它动起来，才出现了那三行。

**编译**：你写的是给人看的文字，电脑看不懂。"把它翻译成一串电脑真能执行的动作"这个步骤，
叫**编译**。`cargo run` 这一个命令其实做了两件事：**先编译，再运行**。
所以你先写、后按一次回车，屏幕上的字才出来——中间那零点几秒就是在翻译。

只这两个词。今天就够用了。

## 6. 你会撞到的报错（三条原话，都是我刚跑出来的）

报错不可怕，它是电脑在跟你说话。而且**它经常指错地方**——这一节把三件怪事都演示给你看。

### ① 把 `main` 改成了别的名字

我做的改动：第一行 `fn main() {` 改成 `fn mian() {`（手滑打反了两个字母）。

```
error[E0601]: `main` function not found in crate `lesson1`
 --> src/main.rs:5:2
  |
5 | }
  |  ^ consider adding a `main` function to `src/main.rs`
```

看清楚了：**我的错在第 1 行，它却在第 5 行（那个 `}`）报错**。
因为它只是翻遍了整个文件，没找到名叫 `main` 的这件事，就在结尾告诉你"找不到"。
遇到这条，第一件事是检查"我有没有一个叫 `main` 的行"，别去改第 5 行。

### ② 少了一个分号

我做的改动：把 `println!("你好，电脑");` 末尾的 `;` 删掉。

```
error: expected `;`, found `println`
 --> src/main.rs:2:22
  |
2 |     println!("你好，电脑")
  |                           ^ help: add `;` here
3 |     println!("我会算数：6 乘 7 等于 {}", 6 * 7);
  |     ------- unexpected token
```

这条很客气：**位置对、还直接教你怎么修**（`help: add ';' here`）。
以后凡是看到 `help:`，先照它说的做，别自己乱猜。

### ③ 引号少关了一个（这条最能骗到人）

我做的改动：把第一句写成 `println!("你好，电脑;`——把内容末尾的引号删掉了。

```
error: unknown start of token: \u{ff1a}
 --> src/main.rs:3:19
  |
3 |     println!("我会算数：6 乘 7 等于 {}", 6 * 7);
  |                       ^^
  |
help: Unicode character '：' (Fullwidth Colon) looks like ':' (Colon), but it is not
```

我改的是第 2 行，报错却在**第 3 行**，而且说的内容像是"你用了中文冒号"——这**不是**我的本意。

原因：中文引号少了右边那个，电脑就以为这句话还没结束，一直往下读，把第 3 行的内容
也当成"要打印的一大段文字"，然后在第 3 行里撞见了它没预料到的符号，就在第 3 行停下来喊你。

所以：**报错的行号只是"它读不下去的位置"，不一定是"你写错的位置"。**
遇到看不懂的报错，先往上几行找有没有没关的引号、没配对的 `{`。

## 7. 练习（做完再看答案）

1. 让你的程序打四行，第三行是你自己的名字。
2. 用一行 `println!` 打出这句话，数字必须是算出来的，不能直接写答案：
   `一周有 7 天，3 周有 21 天。`
3. 把第 2 题的结果打成两行（提示：一句 `println!` 里可以有两个空位；换行要靠多写一句）。
4. 故意做一个错：删掉一个 `}`，跑一次，把你看到的报错**原话**抄到纸上，
   再指出"错在哪一行"和"它报在哪一行"是不是同一处。

### 参考答案

```rust
fn main() {
    // 练习 1：四行，第三行是名字（把我的名字换成你的）
    println!("第一行");
    println!("第二行");
    println!("第三行：张三");
    println!("第四行");

    // 练习 2：21 必须由 7 * 3 算出来
    println!("一周有 {} 天，{} 周有 {} 天。", 7, 3, 7 * 3);

    // 练习 3：拆成两行
    println!("一周有 {} 天", 7);
    println!("{} 周有 {} 天", 3, 7 * 3);
}
```

练习 4 的参考结论：`}` 少一个时，报错通常落在**文件末尾**（因为它一直没等到收尾），
你会再次看到"报错行号 ≠ 犯错行号"这件事。这就是第 6 节第 ③ 条的同类。

## 8. 今天你真正学到的是什么

- 你已经能写出一个能跑的程序，也知道它为什么需要 `cargo run` 才动；
- 你知道 `{}` 是"这里有个空位，按顺序把后面的东西填进来"；
- 你知道报错行号不一定是犯错的地方，**先找没关的引号和没配对的 `{`**；
- 你只学了两个新词：程序、编译。
