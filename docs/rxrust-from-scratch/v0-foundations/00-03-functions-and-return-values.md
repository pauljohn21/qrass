# 第 3 课：把一件事起个名字 —— 函数，以及它交回来的东西

> 零基础第 3 课。已会：**程序**、**编译**、**变量**、**可变**。这一课只加两个新词：
> **函数**、**返回值**。全部代码真跑过，输出原样抄录。

---

## 1. 今天只弄懂一件事

上一课你已经能让电脑记住数。但有些动作要**反复做**：每次算价格都要"减折扣再乘件数"。
如果每次都把这三行重新写一遍，改一次就要改十处。

更省事的做法：**给这件事起个名字**，之后只叫名字。

```rust
fn double(number: i32) -> i32 {
    number * 2
}
```

这一整块读作："我描述一件事，名字叫 `double`。
叫它的时候要给我一个 `i32`（一个整数），它做完**交回**一个 `i32`。"

- 起名字这件事，就叫**函数**。
- 它做完交回来的那个东西，叫**返回值**。

`i32` 你现在只需要认成"整数"的写法（它规定：交进来的必须是整数）。

## 2. 先跑起来看

替换 `src/main.rs`，然后 `cargo run`：

```rust
fn double(number: i32) -> i32 {
    number * 2
}

fn say_hello() {
    println!("你好，我是函数");
}

fn main() {
    say_hello();
    let answer = double(21);
    println!("double(21) = {}", answer);
    println!("套两次：{}", double(double(3)));
}
```

我的真实输出：

```
你好，我是函数
double(21) = 42
套两次：12
```

看最后一行：`double(double(3))` —— 里面那个先算出 6，外面再把它翻倍成 12。
函数可以套着用，就像数学里的 \(f(f(3))\)。

## 3. 你猜会发生什么

| 你把代码改成 | 你猜会怎样 |
|---|---|
| `double(21)` 写成 `double()` | 电脑会自己补一个数吗？ |
| 把 `-> i32` 删掉 | 少了它会怎样？ |
| `double(3)` 写成 `double("3")` | 交进去一个文字行不行？ |

三条都会让电脑拦住你（第 6 节逐条给你原话）。这里先记住一件事：
**叫一个函数的时候，必须按它要求给它东西；它承诺交回的，它也必须真交回来。**

## 4. 一行一行看

```rust
fn double(number: i32) -> i32 {
```
- `fn` = "我要开始描述一件事了"（上一课你已经见过 `fn main`）。
- `double` = 这件事的名字，你起的。
- 括号里 `number: i32` = 叫这件事时**必须给**一个整数；给来的东西在这件事里就叫 `number`。
  名字后面加冒号再写 `i32`，意思是"这个名字只准放整数"。
- `-> i32` = 这件事做完**会交回**一个整数。箭头读作"交回"。

```rust
    number * 2
}
```
- 这一块就是这件事的内容。注意 `number * 2` **末尾没有分号**。
- 没有分号的那个东西，就是**交回去的东西**（返回值）。
- 所以"这件事的内容 = 算 number 的两倍，并把结果交回"。

```rust
fn say_hello() {
    println!("你好，我是函数");
}
```
- 括号里空的：叫它的时候**不用给**任何东西。
- 没有 `->`：它做完**不交回**任何东西，只是做一遍动作（打印一行字）。

```rust
    say_hello();
```
- 叫名字就是让它做一遍。后面跟 `;` 表示"叫完了，这行结束"。

```rust
    let answer = double(21);
```
- 叫 `double`，把 21 交进去；它交回来的 42 被 `answer` 这个变量记住。
- 上节课的知识在这里连起来了：**函数交回来的东西，正好可以放进变量。**

```rust
    println!("double(21) = {}", answer);
    println!("套两次：{}", double(double(3)));
```
- 第一句用变量；第二句不用变量，直接把交回来的东西塞进空位。两种写法都对。

## 5. 两个新词的正式说法（本课仅此两个）

**函数**：一段被起了名字的动作。你可以随时叫这个名字让它再做一遍；
叫的时候可以给它东西（写在括号里），它也可以交回东西（写在 `->` 后面）。

**返回值**：函数做完**交回**给你的那个东西。`let 变量 = 函数(...);` 就是"把交回来的东西记住"。

| 函数长这样 | 要给东西吗 | 会交回东西吗 |
|---|---|---|
| `fn say_hello() { … }` | 不用 | 不交回 |
| `fn double(number: i32) -> i32 { … }` | 要给一个整数 | 交回一个整数 |

## 6. 你会撞到的报错（三条原话，实测）

### ① 叫名字时忘了给东西

我把 `double(21)` 写成 `double()`：

```
error[E0061]: this function takes 1 argument but 0 arguments were supplied
  --> src/main.rs:11:18
   |
11 |     let answer = double();
   |                  ^^^^^^-- argument #1 of type `i32` is missing
   |
note: function defined here
  --> src/main.rs:1:4
```

第一行就说清了："这件事要 1 个东西，你给了 0 个"。
下面的 `note:` 告诉你它的定义在第几行——**去那行看它要什么**，别猜。

### ② 忘了说"我要交回什么"

我把 `-> i32` 删掉：

```
error[E0308]: mismatched types
 --> src/main.rs:2:5
  |
1 | fn double(number: i32) {
  |                       - help: try adding a return type: `-> i32`
2 |     number * 2
  |     ^^^^^^^^^^ expected `()`, found `i32`
```

电脑的意思：你没写 `->`，我就以为你不交回任何东西（那个"什么都不交回"写作 `()`），
可你内容里算了个整数出来，两边对不上。`help:` 照样把答案递给你。

### ③ 交错了东西：给文字当整数

我把 `double(double(3))` 写成 `double("3")`：

```
error[E0308]: mismatched types
  --> src/main.rs:13:31
   |
13 |     println!("套两次：{}", double("3"));
   |                            ------ ^^^ expected `i32`, found `&str`
   |                            |
   |                            arguments to this function are incorrect
```

读法：`^` 指在 `"3"` 上——它要整数，你给了文字。

## 7. 练习（做完再看答案）

1. 写一个函数 `minus_five`，交回"给它的数减 5"。用变量记住结果并打印。
2. 写一个函数 `greeting(name: &str)`，打印 `你好，X。`（提示：`{}` 放在句子里；
   这个函数**不交回**任何东西）。
3. 写一个函数 `area(width: i32, height: i32) -> i32`，算长方形面积。
   调用两次，各打印一次。
4. 先把 `area(3)` 写下来跑一次，抄下报错；再补齐两个数跑对。
   想想：报错有没有告诉你"它要几个东西"？

### 参考答案

```rust
fn minus_five(number: i32) -> i32 {
    number - 5
}

fn greeting(name: &str) {
    println!("你好，{}。", name);
}

fn area(width: i32, height: i32) -> i32 {
    width * height
}

fn main() {
    let result = minus_five(12);
    println!("12 减 5 等于 {}。", result);

    greeting("小美");

    println!("3 × 4 = {}", area(3, 4));
    let room = area(5, 5);
    println!("房间面积 {}。", room);
}
```

第 4 题的报错会长这样（我实测过同类）：`this function takes 2 arguments but 1 argument was supplied`
——它明确告诉你**要几个、你给了几个**，数一下括号里的东西补齐即可。

## 8. 今天你真正学到的是什么

- 函数 = 把一件事起名字，随时叫它做一遍；
- 括号里是"叫它时要给的东西"，`->` 后面是"它交回来的东西"；
- **末尾不写分号的那个东西，就是交回来的东西**；
- 三种常见报错都只问一件事：给的东西对不对、交回的东西对不对。
