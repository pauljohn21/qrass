# 第 4 课：一排数要挨个处理 —— 列表，以及循环

> 零基础第 4 课。已会：**程序**、**编译**、**变量**、**可变**、**函数**、**返回值**。
> 这一课只加两个新词：**列表**、**循环**。代码真跑过，输出原样抄录。

---

## 1. 今天只弄懂一件事

上一课你写了一个函数，一次算一个数。现在有三个学生的分数：10、20、30，
要你算总分，并把每个人的分数都念一遍。

如果一行行写：

```rust
println!("看到 {}", 10);
println!("看到 {}", 20);
println!("看到 {}", 30);
```

三个人还能忍，三百个人呢？所以需要两样新东西：

1. 把一排数**放在一起**记着 → **列表**
2. 对这排东西**挨个做同一件事** → **循环**

## 2. 先跑起来看

```rust
fn main() {
    let scores = [10, 20, 30];
    println!("第二个数是 {}", scores[1]);

    let mut total = 0;
    for score in scores {
        println!("看到 {}", score);
        total = total + score;
    }
    println!("加起来是 {}", total);

    for count in 1..4 {
        println!("第 {} 次", count);
    }
}
```

我的真实输出（一模一样 7 行）：

```
第二个数是 20
看到 10
看到 20
看到 30
加起来是 60
第 1 次
第 2 次
第 3 次
```

## 3. 你猜会发生什么

| 你把代码改成 | 你猜会怎样 |
|---|---|
| `scores[1]` 改成 `scores[0]` | 打印 10 还是 20？ |
| `scores[1]` 改成 `scores[3]` | 这个列表只有 3 个数，位置 3 存在吗？ |
| `for count in 1..4` 改成 `1..5` | 多打一行？ |
| 把 `let mut total = 0;` 的 `mut` 删掉 | 报错还是照跑？ |

第二条很反直觉，我下面用两次真跑分别给你看（一次被电脑当场拦住，一次跑到那一步才停下）。

## 4. 一行一行看

```rust
    let scores = [10, 20, 30];
```
- 方括号 `[ ]` 把一排数装在一起，起名叫 `scores`。这样一个变量就记住了**一排**值。
- 这一排放在一起的东西，就叫**列表**。

```rust
    println!("第二个数是 {}", scores[1]);
```
- `scores[1]` 读作"拿 `scores` 里位置 1 的东西"。
- **位置从 0 开始数**：`scores[0]` 是 10，`scores[1]` 是 20，`scores[2]` 是 30。
  这是新手最容易踩的坑：第 n 个东西在位置 `n - 1`。

```rust
    let mut total = 0;
```
- 要边看边累加，就得改这个变量 → 所以这里必须写 `mut`（第 2 课的知识在这儿用上了）。

```rust
    for score in scores {
```
- 这一行是**循环**的开头："`score` 依次代表列表里的每一个数，每代表一个，就把大括号里的话做一遍"。
- 大括号里的 `score` 就是"当前看到的那个数"，它只在括号里有用。
- 做完一个，电脑自动换下一个，直到列表里没有下一个了，就跳出括号。

```rust
        println!("看到 {}", score);
        total = total + score;
    }
```
- 打印当前这个数；再把它加进 `total`。
- 三次数做完，`total` 就是 10 + 20 + 30 = 60。

```rust
    println!("加起来是 {}", total);
```
- 循环外面还能用 `total`——它是循环**开始前**就记下的变量，所以循环里一直在改的就是它。

```rust
    for count in 1..4 {
        println!("第 {} 次", count);
    }
```
- `1..4` 是"从 1 开始，到 4 之前结束"：**含头不含尾**。
  所以是 1、2、3，共三次（这就是为什么屏幕上是 `第 1 次`、`第 2 次`、`第 3 次`）。
- 想要 4 也打出来，写 `1..5`。

## 5. 两个新词的正式说法（本课仅此两个）

**列表**：用方括号放在一起的一排值，比如 `[10, 20, 30]`。用 `名字[位置]` 拿其中一个，
位置从 0 开始数。

**循环**：`for 名字 in 列表 { … }`，意思是"对里面每一个东西，把大括号里的话做一遍"。
`1..4` 这种写法叫"从 1 数到 4 之前"。

| 你想干什么 | 写法 |
|---|---|
| 拿第一个数 | `scores[0]` |
| 数一共几个数 | `scores.len()` |
| 每个都做一遍 | `for score in scores { … }` |
| 重复固定次数 | `for count in 1..4 { … }` |

## 6. 你会撞到的报错（四条原话，实测）

### ① 忘了 `mut` 就要累加

把 `let mut total = 0;` 的 `mut` 删掉：

```
error[E0384]: cannot assign twice to immutable variable `total`
 --> src/main.rs:8:9
  |
5 |     let total = 0;
  |         ----- first assignment to `total`
...
8 |         total = total + score;
  |         ^^^^^^^^^^^^^^^^^^^^^ cannot assign twice to immutable variable
```

和上一课同一条：累加就是"换值"，所以要 `mut`。注意报错在**循环里面**那一行，
但真正要改的是**循环外面**那句 `let`——又是"报错行号 ≠ 该改的地方"。

### ② 位置数过头：写死的数字，电脑当场拦住

我把 `scores[1]` 改成 `scores[3]`（这个列表只有 3 个数）：

```
error: this sequence has an unconditional panic
  = note: `#[deny(unconditional_panic)]` on by default
```

电脑直接拒绝让你跑起来——因为它能算出"位置 3 一定不存在"。
这条其实是在帮你：这种错还没跑就修掉了。

### ③ 同样是数过头，但如果电脑算不出来，就要跑到那一步才炸

把位置换成"要运行时才知道"的东西（这里让另一个函数交回 3）：

```rust
fn pick() -> usize {
    3
}

fn main() {
    let scores = [10, 20, 30];
    println!("第 {} 个数", scores[pick()]);
}
```

跑起来是真的炸（编译能过）：

```
thread 'main' panicked at src/main.rs:7:28:
index out of bounds: the len is 3 but the index is 3
```

这条原话很实用：它说"长度是 3，你却要位置 3"。位置 3 是**第 4 个**，最大只能到 2。
所以：**先数列表里有几个，再决定位置能写到几**。

### ④ 方括号没关上

把 `[10, 20, 30]` 写成 `[10, 20, 30`：

```
error: mismatched closing delimiter: `}`
  --> src/main.rs:2:18
   |
 1 | fn main() {
   |           - closing delimiter possibly meant for this
 2 |     let scores = [10, 20, 30;
   |                  ^ unclosed delimiter
```

它猜你的 `}` 其实是想关那个 `[`。看到 `unclosed delimiter`（没关上的括号），
就回头数括号：`[ ]`、`( )`、`{ }` 是不是都成对。

## 7. 练习（做完再看答案）

1. 造一个列表装四个数，打印"最后一个数"。（提示：先想位置是几。）
2. 用循环把列表里每个数都打印两行：一行"原始值"，一行"它的三倍"。
3. 用循环算 `[2, 4, 6, 8]` 里面有几个数（自己数，不能用 `len()`）。
4. 把 `for count in 1..4` 改成 `0..4`，先猜打印几行，再跑。
5. 上一课的函数接上这一课：写一个函数 `triple(number: i32) -> i32`，
   在循环里对每个数调用它并打印结果。

### 参考答案

```rust
fn triple(number: i32) -> i32 {
    number * 3
}

fn main() {
    let numbers = [5, 7, 9, 11];
    println!("最后一个数是 {}", numbers[3]);

    for number in numbers {
        println!("原始值 {}", number);
        println!("它的三倍 {}", triple(number));
    }

    let mut count = 0;
    for number in [2, 4, 6, 8] {
        println!("看到 {}", number);
        count = count + 1;
    }
    println!("一共 {} 个数", count);

    // 练习 4：`0..4` 会打印 4 行（0、1、2、3），不是 3 行。
    for position in 0..4 {
        println!("位置 {}", position);
    }
}
```

第 1 题最容易写错：四个数的最后一个位置是 **3**，不是 4。

## 8. 今天你真正学到的是什么

- 列表把一排值放在一起；位置从 **0** 开始数；
- 循环 = 对里面每个东西做一遍；`1..4` **含头不含尾**；
- 累加需要 `mut`（因为你在换值）；
- 同一个错（数过头）可能被当场拦住，也可能跑到那一步才炸——
  区别只是"电脑能不能提前算出来"。

**下一课**是这门课前半段最关键的一课：**值有主人**。
你会看到"把东西交出去之后，原来的名字就不能用了"这件事——
它是 Rust 和其他语言最不一样的地方。
